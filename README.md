# SEO Lizards WordPress Theme

A lightweight, responsive WordPress blog theme.

## Included
- Blog homepage loop (`index.php`)
- Single post and page templates (`single.php`, `page.php`)
- Header, footer, sidebar, and comments templates
- Custom menu, logo, header-image, featured image, and widget support
- Theme preview image (`screenshot.png`)

## Using custom header images
1. Activate the theme in WordPress.
2. Go to **Appearance → Header** and upload your image.
3. Assign a menu to **Primary Menu** and add widgets to **Sidebar**.
